# Установка Троя вручную (VPS + Windows)

> Пока это ручная установка. Скоро её заменит мастер: Трой сам спросит всё нужное в чате.
> Локальный режим (без VPS) и macOS — в работе.

## Что понадобится

- **VPS** на Ubuntu 22.04 или новее (хватит 1 ядра и 1 ГБ памяти), его IP-адрес и пароль root.
- **Компьютер с Windows 10/11** и установленным Python 3.10+ (python.org, галочка «Add to PATH»).
- **Telegram-бот:** напишите @BotFather → `/newbot` → скопируйте токен.
- **Ключ Groq** (бесплатно, без карты): console.groq.com → API Keys → Create API Key.
- По желанию: ключ Mistral (запасной, бесплатный), вебхук Битрикс24, приватный репозиторий GitHub для идей.

## 1. Настройки

1. Скачайте этот репозиторий: зелёная кнопка **Code → Download ZIP**, распакуйте.
2. В папке `server` скопируйте `settings.env.example` в `settings.env` и впишите токен бота и ключ Groq.
   `ALLOWED_USER_ID` пока оставьте пустым.

## 2. Сервер

1. Запустите `server\deploy.bat`, введите IP сервера и (один раз) пароль.
2. Скрипт поставит Трой на сервер службой `sometroy`, создаст сертификат и положит в папку `desktop`
   файлы `troy-cert.pem` и `config.json` для программы на компьютере.
3. Напишите своему боту в Telegram — он пришлёт ваш ID. Впишите его в `ALLOWED_USER_ID`
   и снова запустите `deploy.bat`. Теперь бот отвечает только вам.

Обновление кода позже — `server\update.bat` (настройки, напоминания и история не трогаются).

## 3. Программа на компьютере

1. Запустите `desktop\build.bat` — он соберёт программу и установщик `SomeTroySetup.exe`
   (сборщик Inno Setup поставится сам через winget).
2. Установите. Пароль для входа задайте в Telegram: `/password ваш_пароль` — сообщение сразу удалится.
3. Установщик можно ставить и на другие компьютеры: паролей внутри нет.

## Что умеет

- текст, голосовые, фото и PDF; напоминания; поиск в интернете; идеи по проектам;
- Битрикс24 (если указан вебхук): задачи, чаты, CRM, аналитика — всё, что меняет, только после вашего «да»;
- управление компьютерами, где запущена программа: открыть/закрыть программы, музыка, громкость,
  блокировка, сон, выключение и перезагрузка (после «да»). Несколько компьютеров — Трой покажет кнопки.

Команды в Telegram: `/help`, `/status`, `/reminders`, `/ideas`, `/new`, `/password`, `/devices`, `/apps`.

## Если что-то не так

- Журнал на сервере: `journalctl -u sometroy -f`
- Проверка ключей: `cd /opt/sometroy && venv/bin/python bot.py --check`
- Всё, что вы пишете Трою, обрабатывают модели Groq (и Mistral, если указан). Паспорт, банковские данные
  и пароли ему не отправляйте.
