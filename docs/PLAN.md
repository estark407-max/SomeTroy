# SomeTroy — Трой для всех

> Бесплатный некоммерческий проект: оболочка, с которой любой человек сам ставит себе своего Троя
> на свои мощности. Troy — личный продукт Егора и Claude; SomeTroy — название проекта для всех.
> Имя ассистента везде неизменное — «Трой».

## Решения (2026-11-01)

- Полностью бесплатно и некоммерчески, для любого человека.
- Человек ставит сам; Трой помогает по шагам прямо в чате. Никаких платных внешних сервисов.
- При установке выбор: **локальный Трой** (всё на компьютере, работает, пока компьютер включён)
  или **свой VPS** (адрес и пароль человек вводит сам; мы даём только оболочку).
- Пасхалки и отсылки — во всех версиях: «Возможно, вы помните меня по таким фильмам, как…»,
  эпиграмма про лысого бородатого человека и сверхумную машину, «© 2026 Claude и Egor Zhidetskiy».

## Как будет устроено

1. **Ядро без личного.** Из кода Троя убрать всё зашитое под Егора (Telegram ID, портал Битрикса,
   котёл, репозиторий идей, имена компьютеров) — всё в настройки.
2. **Модули по выбору:** Telegram, Битрикс24, идеи в GitHub, управление компьютерами,
   котёл DM350 (только для владельцев таких котлов).
3. **Мастер первой настройки в чате.** Ведёт обычный код по сценарию, НЕ модель — ключи и пароли
   в ИИ не уходят. Шаги: локально или VPS → (VPS: адрес, пароль, установка серверной части) →
   бесплатный ключ Groq (ссылка и подсказка) → бот от BotFather → «напиши боту» (так узнаём ID
   хозяина) → пароль программы → модули.
4. **Локальный режим:** серверная часть живёт внутри программы на компьютере, Telegram работает,
   пока компьютер включён. Без сертификатов и открытых портов.
5. **Раздача:** открытый репозиторий с установщиком SomeTroy.exe и инструкцией.

## macOS (2026-11-01)

- Нужна оболочка Троя и под macOS — и для SomeTroy, и для личного Troy.
- Окно: вместо Edge — встроенное окно macOS (WebKit, через pywebview) — тот же интерфейс ui.html.
- Значок в строке меню вместо трея; голос по сочетанию клавиш (macOS попросит разрешение
  «Универсальный доступ»).
- Управление компьютером: открыть/закрыть программу (open -a / quit), музыка и громкость,
  блокировка, сон, выключение и перезагрузка — через встроенные команды macOS.
- Сборка .app / .dmg — только на Mac. Без своего Mac — бесплатно в GitHub Actions
  (для открытого репозитория), сборка под Windows и macOS сразу.
- Подпись Apple стоит денег ($99/год) — не используем. При первом запуске: правый клик → «Открыть»
  (в инструкции и в самом Трое — подсказка с картинкой).

## Решено

- Раздача — отдельный публичный репозиторий SomeTroy; личный Troy не трогаем, код копируется сюда
  уже очищенным от личных настроек.
- Иконка — свой рисунок: ретро-телевизор с ведущим и указкой учебного ролика (art/).
- Лицензия — MIT.

## Порядок работ (~2–3 вечера)

2. Мастер первой настройки в чате.
3. Локальный режим.
4. Оболочка под macOS.
